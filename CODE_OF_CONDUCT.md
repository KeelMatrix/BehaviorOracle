# Code of Conduct

Contributors and maintainers are expected to be respectful, constructive, and inclusive. Harassment, discrimination, threats, doxxing, and personal attacks are not acceptable.

Report conduct concerns privately to **keelmatrix@gmail.com** with the repository, relevant links or dates, and only the supporting context needed to investigate. Do not include credentials, customer data, library inputs, or generated witnesses. Vulnerability reports must follow [`SECURITY.md`](SECURITY.md).
